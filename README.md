## Features & Highlights

- **Responsive Layout:** Designed from mobile viewports up to large desktop monitors using modern CSS Flexbox and CSS Grid modules.
- **WCAG Accessibility Compliance:** Form elements, landmarks, heading hierarchies (`<h1>`-`<h6>`), and navigation links adhere to semantic web accessibility guidelines.
- **Multi-Page Architecture:** Includes a dedicated Home page (`index.html`), About page (`about.html`), Projects showcase (`projects.html`), and Contact page (`contact.html`).
- **Interactive Contact Form:** Standardized contact interface featuring accessible form controls, input field labels, and submission structure.
- **Modular Stylesheets:** Standardized rules for typography, layout grids, global color palettes, and responsive media query breakpoints.

## Key Lessons & Core Concepts Learned

During Week 03 of the IYF Season 12 curriculum, our team focused on scaling up from single-page layouts to complete multi-page web applications. Key takeaways include:

1. **Semantic HTML Architecture:** Understanding how structured tags improve screen reader accessibility and search engine optimization (SEO).
2. **CSS Layout Engines (Flexbox vs. Grid):**
   - Utilizing **Flexbox** for one-dimensional layouts such as navigation bars, headers, and form action areas.
   - Utilizing **CSS Grid** for two-dimensional layouts such as project card galleries and multi-column article sections.
3. **Collaborative Git Workflows:**
   - Managing feature branches to avoid pushing unverified code directly to `main`.
   - Authoring standard Pull Request descriptions for peer feedback.
   - Identifying, understanding, and resolving Git merge conflicts safely during feature merges.
